# Settings Reference Index

This appendix set documents every preference declaration that the APK 1031 research extracted: **500 screen/key declarations across 42 settings screens**, using **452 distinct preference keys** (17 keys appear on more than one screen and are documented on each). Each page lists the exact key, control type, declared default, option values or numeric range, dependencies, resource files, and evidence notes.

The chapters explain what the settings do and when they matter; these pages are the dependable lookup. When a chapter and an appendix appear to disagree on a declared value, the appendix is authoritative because it is generated directly from the extracted catalog.

## How to read the reference

- **Declared default** is the `android:defaultValue` attribute in the XML. “Not declared” means the XML is silent; it does **not** mean Off, zero, or disabled. A declared default also does not prove what a given installation currently uses.
- **Values / range** gives option labels with their stored values, or the numeric range converted with the declared scale and display format (for example `-600` with scale 100 and format `%.1fdB` is shown as −6.0 dB). Raw values are kept in back-ticks.
- **Option labels** come from the APK string resources resolved during the research phase. Labels marked † have no declared stored values; the positional mapping (first option = `0`) is an **unverified inference**. Build 1031 also declares lists numbered from `1` (`queue_start`) or out of order (`queue_insert_pos`, `cc_button`, `anim_speed`), so a † value or default can point at the wrong option.
- **Markers:** *Experiment* (`app:sup`), *Feature Pack* (`app:featurePack`), *non-persistent* (`android:persistent="false"`).
- Where `xml/` and `xml-v22/` variants exist they differ only in a cosmetic `android:singleLineTitle` attribute on 43 entries; both files are listed as sources. 74 declarations exist only in `xml/`.
- **APK text** fields quote text from the Poweramp Player application verbatim. That text belongs to its owner and is reproduced for identification and reference; see the Cover's third-party text notice.
- “APK VERIFIED” here means consistent with the extracted build 1031 resources used during research. Those resources are not distributed with this handbook, and a declaration does not prove runtime behaviour.
