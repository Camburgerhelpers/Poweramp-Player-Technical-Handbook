# 34. Background Operation and Compatibility

Android aggressively limits background apps to save battery, and device makers often go further. A music player has to keep playing with the screen off, survive memory pressure, and come back reliably. Build 1031 contains several settings that help with this, plus a set of experimental and compatibility switches for particular devices and Android versions. This chapter puts them in a sensible order: system settings first, Poweramp workarounds second.

## Step 1: let Android run Poweramp in the background

**GENERAL PRINCIPLE.** Before you use any workaround, allow background activity for Poweramp in Android's battery settings (named “Unrestricted” or “Don't optimise” on many devices) and exempt it from any vendor battery manager. Poweramp's own APK text recommends exactly this, preferring it over the silence workaround below.

The main Settings menu can show two runtime warnings, `manage_app_warn` and `perm_warn`, whose text is generated by the app. **RESEARCH SUPPORTED:** these presumably flag background-management and permission problems respectively.

| Play silence in background <sup>non-persistent</sup> | `play_silence_in_background` | Switch | Not declared | — | — |

*Source: APK build 1031 settings XML — reference: [Notification Settings](../Appendices/Settings%20Reference/Notification%20Settings.md), [Miscellaneous Settings](../Appendices/Settings%20Reference/Miscellaneous%20Settings.md), [Individual Audio Output Settings](../Appendices/Settings%20Reference/Individual%20Audio%20Output%20Settings.md).*


- **Keep Service:** “Poweramp player service won't be unloaded when in idle” “On Android 8+ this option works reliable only with the active notification”.
- **Keep Notification:** “Notification stays even if Poweramp paused in its UI, when playback auto-ends, etc”.
- **Keep Inactive Media Notification:** a firmware-dependent media suggestion may permit resuming the player while it is inactive ([Chapter 30 — Notifications and Media Buttons](30%20Notifications%20and%20Media%20Buttons.md)).
- **Use Wakelock:** “Check this if audio stops when screen is off”.
- **Play silence in background** (per output): “Helps keeping player uninterrupted in the background. Increases battery usage” Android's background permissions are preferable to continuous silent playback for keeping the player active.

Apply them in that order and stop when the problem is solved. Each later step costs more battery.

> [!WARNING]
> **Experimental and undocumented switches**
> **Load custom .so library**, **Override Region**, **Apply OP High Framerate** and **Pause on Screen Off** either carry the APK's “Experiment” marker or have no description. Change them only with a specific reason, one at a time, and note the original values first. **Load custom .so library** loads native code into Poweramp: never point it at a library from an untrusted source.

## Shutdown handling

**Shutdown Intent** lets Poweramp pause and save its state when a named broadcast arrives ([Chapter 33 — Scrobbling and App Integration](33%20Scrobbling%20and%20App%20Integration.md)). It helps only where a device or app sends that broadcast before power is lost; an abrupt power cut sends no broadcast.
